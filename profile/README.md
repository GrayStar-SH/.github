## Concept / コンセプト / 概念

> *灰星の下で、私たちは動き出す*  
> *在灰星之下，我们继续前行*  
> *Under GrayStar, we begin*

- 不定义边界。不做明确分类。只记录和实验——游戏、AI、奇怪的代码、还没想清楚在做什么的项目。灰星不是一个类型，是一个方向：向未知延伸，向未开发探索。
- 明確な境界線も、明確な分類もない。ただひたすら記録と実験を続ける――ゲーム、AI、奇妙なコード、目的がまだはっきりしないプロジェクトなど。グレイ・スターはカテゴリーではなく、方向性を示すもの――未知の領域へと広がり、未踏の地を探求する。
- No defined boundaries. No explicit categorization. Just recording and experimenting—games, AI, strange code, projects whose purpose isn't yet clear. Gray Star isn't a category, but a direction: extending into the unknown, exploring the unexplored.
